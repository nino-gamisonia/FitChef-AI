# 🏋️‍♂️ FitChef AI — პერსონალური ფიტნეს მწვრთნელი და ნუტრიციოლოგი

**FitChef AI** არის ინტელექტუალური AI აგენტი, რომელიც აგებულია **LangGraph**, **Google Gemini**, **Groq** და **Streamlit** ტექნოლოგიებზე. აპლიკაცია მომხმარებელს ეხმარება პერსონალიზებული კვების რაციონის, ვარჯიშის გეგმის შედგენასა და მაცივარში არსებული პროდუქტების ფოტოთი ანალიზში.

---

## ✨ ძირითადი ფუნქციები

* **პერსონალიზებული AI ჩატი (LangGraph Agent):** იმახსოვრებს მომხმარებლის პროფილს (მიზანი, წონა, სიმაღლე, ალერგიები) და იყენებს სპეციალურ ინსტრუმენტებს (Tools) ზუსტი რეკომენდაციებისთვის.
* **მაცივრის სკანერი (Computer Vision):** ატვირთული ფოტოდან ამოიცნობს პროდუქტებს (`vision.py`) და სთავაზობს ჯანსაღ რეცეპტებს.
* **ინტერაქტიული ვებ-ინტერფეისი (Streamlit):** მარტივი და თანამედროვე სამომხმარებლო ინტერფეისი (`app.py`) გვერდითი პანელითა და პარამეტრების მართვით.
* **CLI რეჟიმი:** აგენტთან პირდაპირ ტერმინალიდან კომუნიკაციის შესაძლებლობა (`cli.py`).

---

## 📁 პროექტის სტრუქტურა

* `app.py` — Streamlit ვებ-აპლიკაციის მთავარი ინტერფეისი.
* `agent.py` — LangGraph აგენტის ლოგიკა, მდგომარეობის მართვა (MemorySaver) და LLM ინტეგრაცია.
* `tools.py` — აგენტის დამხმარე ხელსაწყოები (კალორიების გამოთვლა, ვარჯიშისა და კვების გეგმის გენერაცია და სხვ.).
* `vision.py` — სურათების ანალიზის მოდული პროდუქტების ამოსაცნობად.
* `cli.py` — აგენტის ტერმინალში (Command Line) გასაშვები ვერსია.
* `requirements.txt` — პროექტისთვის საჭირო Python ბიბლიოთეკების სია.
